# Garry's Mod | Custom Menu

### Как установить?

- Скачиваем [актуальную версию](https://github.com/Nexeonenn/custom_menu/archive/refs/heads/installer.zip) установщика.
- Открываем его и ждём окончания установки.
- Радуемся жизни!
